# Narrated demo outline

Run `bash app.sh --demo` in a comfortably sized terminal. This is an isolated
sample library, but live recommendations use your Codex allowance. Check your
login and allowance before recording. Aim for roughly 2–3 minutes.

1. **Add a book.** Choose Add Book, enter a fantasy title, choose metadata lookup,
   select a match, review it, and save. Browse the library to show persistence
   within this demo session. Explain that only the data layer writes the CSV.
2. **Update reading progress.** Select a demo book and mark it finished with a
   rating. Browse its details. Explain how the menu asks the workflow to call
   the storage component.
3. **Get recommendations.** Enter a fantasy interest. Show the three running
   statuses, then open a result and read its reason. Explain `&`, `$!`, `wait`,
   and the combine/refine pipe. Save one recommendation after reviewing details.

Use your own words and explain only behavior you can demonstrate. AI calls can
vary in duration; a clearly labeled cut is fine if your course permits editing.

Upload your narrated recording to the repository or a viewable video host, then
put a prominent link in the README. Verify the instructor can access the link.
